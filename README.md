# Sine Studio

Bilingual landing page for https://sinestudio.co.nz linking to Sine Driving School and SafeINNZ.

## Deploy

Import this repository into Vercel. Framework: Other. Root directory: repository root. No installation or build is required; vercel.json declares the static output directory.

Production branch: main. Updates pushed to main deploy automatically after the Git integration is connected.

## Domains

Add sinestudio.co.nz and www.sinestudio.co.nz in Vercel Project Settings > Domains. Redirect www to https://sinestudio.co.nz. At Porkbun, use the exact DNS records provided by Vercel; leave the Host blank for the apex domain. Preserve unrelated email MX and TXT records.

Optionally add sine.studio and sine.co.nz to the same project and redirect them to https://sinestudio.co.nz.
